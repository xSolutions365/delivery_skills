# CreateFuture Delivery Starter Project

This is a starter template for new CreateFuture delivery projects using Claude Code. It pre-configures the CreateFuture delivery plugin marketplace so all team skills are available out of the box.

## How to Use

1. Copy the contents of this folder into your project root
2. Open your project in Claude Code
3. You'll be prompted to install the CreateFuture delivery marketplace — accept it
4. Run `/agent-setup:customise-agent` to personalise the agent for your name, role, and current project
5. Start working — type `/` to see all available skills

## What's Included

- **CLAUDE.md** — Template agent config with CreateFuture delivery context and placeholder sections. The `/agent-setup:customise-agent` skill will help you fill these in.
- **.claude/settings.json** — Pre-configured to auto-enable all CreateFuture delivery marketplace plugins.

## Available Plugins

Once installed, you'll have access to:

- **delivery-tooling** — New project KB setup, GitHub repo creation, team onboarding
- **agent-setup** — Interactive agent personalisation wizard
