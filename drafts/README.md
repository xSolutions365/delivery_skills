# Drafts

A place to share a skill while you are still trying it out. Nothing in this
folder is installable, so it never appears in anyone's Claude.

## Share a draft

1. Add a folder here named after the skill, containing its `SKILL.md`.
2. Open a pull request and tell the team where it is.
3. To try someone's draft, copy its folder into `~/.claude/skills/`.

## Promote a draft

Once other people are using it, move the folder into the plugin it belongs to
under `plugins/<plugin>/skills/` and add it to the catalogue. See
[Contributing](../CONTRIBUTING.md).
